# MacGyver3
# Sistema de Gestão Interna - DeltaV Rocketry

Este repositório é a base de código da **terceira geração do Sistema de Gestão Interna da DeltaV Rocketry**, um ecossistema digital desenvolvido para ser o pilar administrativo e operacional da equipe. Esta versão v3.0 não é apenas uma atualização, mas uma reconstrução estratégica consolidada após dois ciclos experimentais de desenvolvimento, testes e implementação prática em ambiente acadêmico.
Diferente das iterações anteriores, que serviram como Provas de Conceito (PoC), a versão atual transcende o estágio de prototipagem para ser um primeiro estágio de desenvolvimento com o objetivo de estabelecer como uma **ferramenta de gestão plena e robusta**. O projeto foi refinado para endereçar gargalos operacionais identificados historicamente, introduzindo avanços significativos na arquitetura do sistema e na experiência do usuário (UX), garantindo que a tecnologia acompanhe a complexidade crescente dos projetos aeroespaciais da equipe

## 🚀 Sobre o Projeto

O sistema foi concebido para centralizar a administração da equipe, facilitando o acompanhamento de cronogramas, gestão de coordenação entre os diferentes subsistemas, como Aviônica, Propulsão e Estrutura. O objetivo principal é garantir a transparência e a eficiência acadêmica.

### Principais Funcionalidades

* **Gestão de Membros:** Controle de presença e atribuição de cargos e responsabilidades.
* **Cronograma de Atividades:** Acompanhamento de sprints e prazos de entrega dos projetos.
* **Dashboard de Recursos:** Visualização clara da alocação de verba e materiais por subsistema.

## 🛠️ Tecnologias Utilizadas

* **Linguagens:** JavaScript(tecnologias conjuntas - React), HTML, CSS, Python(tecnologias conjuntas) e MySql.
* **Ambiente digital:** Azure, Azure Cloud, Azure Web
